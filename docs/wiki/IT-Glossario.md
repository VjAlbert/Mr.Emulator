# 📚 Glossario

| Termine | Significato |
|---|---|
| **ROM** | Un file con il contenuto di una cartuccia o di un disco di gioco (o di una scheda arcade). |
| **BIOS** | Il firmware di sistema di cui alcune console hanno bisogno per partire (PlayStation, Neo Geo, Dreamcast…). |
| **Emulatore / core** | Un programma (o libreria) che imita una console. In RetroArch ogni emulatore è un **core**. |
| **libretro / RetroArch** | libretro è l'interfaccia che i core implementano; RetroArch è il programma che carica i core e gestisce video, audio e comandi. |
| **MAME** | L'emulatore arcade multi-sistema. Usato in modo autonomo da *Arcade (MAME)*. |
| **FBNeo (FinalBurn Neo)** | Un emulatore arcade/console veloce, disponibile come core di RetroArch. |
| **Set di ROM (merged / split / non-merged)** | Come MAME organizza giochi principali e cloni negli ZIP. Un set vale solo per **la sua versione di MAME**. |
| **Principale / clone (variante)** | Un gioco e le sue versioni regionali o riviste. |
| **CHD** | Formato di immagine disco compressa usato da MAME e altri per hard disk e CD. |
| **File DAT** | Un elenco di giochi con nomi e checksum (FinalBurn Neo, MAME…). Serve a mostrare i titoli veri. |
| **Software List** | Il database di MAME con i nomi di software per console e computer. |
| **`.m3u`** | Una piccola playlist che raggruppa i dischi di un gioco a più dischi. |
| **Stato di salvataggio** | Un'istantanea dell'intero emulatore. Usato per «Continua». |
| **SRAM / memory card** | I dati di salvataggio del gioco stesso. |
| **RetroAchievements** | Un servizio gratuito che aggiunge trofei ai giochi retro. La **modalità hardcore** disattiva stati e trucchi. |
| **Trucco (cheat)** | Un codice che modifica un gioco (vite infinite…). RetroArch ha un database di trucchi. |
| **Overlay / bordo / bezel** | Una grafica disegnata ai lati (o intorno) all'immagine del gioco. |
| **Shader** | Un piccolo programma che cambia l'aspetto dell'immagine (righe CRT, ammorbidimento). I preset sono file `.slangp`. |
| **Effetto CRT** | Uno shader che imita righe e curvatura dei vecchi televisori a tubo. |
| **sharp-bilinear / xBRZ** | Shader di nitidezza dei pixel: ammorbidimento leggero / linee oblique pulite. |
| **Scala intera (pixel perfetti)** | Ingrandire solo di numeri interi, così ogni pixel è un quadrato perfetto. |
| **Run-ahead** | Funzione di RetroArch che riduce il ritardo dei comandi facendo correre i fotogrammi in anticipo. |
| **Hat** | Una croce direzionale riportata come asse speciale da alcuni gamepad. |
| **I-PAC** | Un diffuso encoder a tastiera per pannelli arcade. |
| **Tate** | Un monitor arcade montato in verticale (ruotato). |
| **Pacchetto Multimedia** | Un insieme di immagini (snap, flyers, titles), video e musica per giochi MAME/arcade. |
| **Snap / flyer / title** | Schermata di gioco / la pubblicità originale / la schermata del titolo. |
| **Attract mode** | La dimostrazione che gira a riposo (qui: copertine che ruotano). |
| **Cache** | Cartella locale dove si tengono le copertine scaricate. |
