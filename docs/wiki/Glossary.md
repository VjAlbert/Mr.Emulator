# 📚 Glossary

| Term | Meaning |
|---|---|
| **ROM** | A file with the contents of a game cartridge or disc (or an arcade board). |
| **BIOS** | System firmware some consoles need to start (PlayStation, Neo Geo, Dreamcast…). |
| **Emulator / core** | A program (or library) that imitates a console. In RetroArch each emulator is a **core**. |
| **libretro / RetroArch** | libretro is the interface cores implement; RetroArch is the program that loads cores and handles video, audio and input. |
| **MAME** | The multi-system arcade emulator. Used standalone by *Arcade (MAME)*. |
| **FBNeo (FinalBurn Neo)** | A fast arcade/console emulator available as a RetroArch core. |
| **ROM set (merged / split / non-merged)** | How MAME arranges parent and clone games in ZIPs. A set only fits **its own MAME version**. |
| **Parent / clone (variant)** | A game and its regional or revision versions. |
| **CHD** | Compressed disk image format used by MAME and others for hard disks and CDs. |
| **DAT file** | A list of games with names and checksums (FinalBurn Neo, MAME…). Used to show real titles. |
| **Software List** | MAME's database of console/computer software names. |
| **`.m3u`** | A small playlist that groups the discs of a multi-disc game. |
| **Save state** | A snapshot of the whole emulator. Used for "Continue". |
| **SRAM / memory card** | The game's own save data. |
| **RetroAchievements** | A free service that adds trophies to retro games. **Hardcore mode** disables save states and cheats. |
| **Cheat** | A code that changes a game (infinite lives…). RetroArch has a database of them. |
| **Overlay / border / bezel** | Artwork drawn on the sides (or around) the game picture. |
| **Shader** | A small program that changes how the picture looks (CRT lines, smoothing). Presets are `.slangp` files. |
| **CRT effect** | A shader imitating the lines and curvature of old tube TVs. |
| **sharp-bilinear / xBRZ** | Pixel-sharpness shaders: soft smoothing / clean diagonal lines. |
| **Integer scaling (pixel perfect)** | Enlarging by whole numbers only, so every pixel is a perfect square. |
| **Run-ahead** | A RetroArch feature that reduces input lag by running frames ahead. |
| **Hat** | A D-pad reported as a special axis by some gamepads. |
| **I-PAC** | A popular keyboard-style encoder for arcade panels. |
| **Tate** | A vertically mounted (rotated) arcade monitor. |
| **Multimedia pack** | A set of images (snaps, flyers, titles), videos and music for MAME/arcade games. |
| **Snap / flyer / title** | In-game screenshot / the original advert / the title screen. |
| **Attract mode** | Demo that plays while idle (here: rotating covers). |
| **Cache** | Local folder where downloaded covers are kept. |
